1. Aceptación de los Términos

Al acceder a la plataforma web de TechEcom COD, solicitar una demostración técnica o integrar nuestros servicios de middleware (MaaS), usted acepta cumplir con estos Términos de Servicio y con todas las leyes y regulaciones aplicables.

2. Descripción del Servicio Middleware (MaaS)

TechEcom COD proporciona una capa middleware distribuida para la verificación, scoring de riesgo, geofencing y orquestación de datos de pedidos para e-commerce operando bajo el esquema Pago Contra Reembolso (Cash on Delivery). TechEcom COD actúa como intermediario tecnológico entre plataformas de comercio electrónico (ej. Shopify, WooCommerce) y proveedores logísticos / plataformas de dropshipping (ej. Dropi, BigBuy).

3. Responsabilidades del Usuario / Comercio

El cliente o usuario se compromete a:

  • Suministrar información veraz durante el proceso de registro y configuración técnica.
  • Hacer uso adecuado de los Webhooks, API Keys y credenciales de acceso asignadas.
  • Garantizar que la recolección de datos de sus compradores finales cumple con la normativa de comercio electrónico de sus mercados de operación.

4. Limitación de Responsabilidad

TechEcom COD optimiza y automatiza los filtros Anti-RTO para reducir el índice de rechazo en entregas; sin embargo, no garantiza el cobro o efectividad del 100% de los envíos, dado que la entrega física final depende de terceros logísticos y de la recepción por parte del comprador final.
