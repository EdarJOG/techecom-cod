# Middleware & Anti-RTO Logistics Showcase

Showcase para operaciones de e-commerce COD (Cash on Delivery), calculadora interactiva de ROI y flujos de integración API.

## 🚀 Descripción del Proyecto
Este repositorio contiene la arquitectura y lander web para la demostración de soluciones middleware, optimización de entregas COD y prevención de devoluciones (Anti-RTO) en plataformas de e-commerce.

## 📁 Estructura del Repositorio
- `index.html`: Página principal del sitio.
- `gracias.html`: Página de confirmación/agradecimiento.
- `privacidad.html`: Políticas de privacidad.
- `terminos.html`: Términos y condiciones del servicio.
- `_headers`: Configuración de cabeceras HTTP para despliegue.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS
- **Despliegue & Hosting:** GitHub Pages / Cloudflare Pages
- **Integración Backend:** Arquitectura de APIs / Webhooks agnósticos (compatible con REST APIs, plataformas No-Code / Automation y ERPs)
